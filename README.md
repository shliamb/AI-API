# Документация к API для верификации пользователя и взаимодействия с OpenAI

## Общее описание
Данный API предоставляет возможность верификации пользователей по их имени и приложенческому ключу (appkey), а также осуществляет взаимодействие с моделью OpenAI для обработки текстовых сообщений.

### Эндпоинты
1. Верификация пользователя
2. Взаимодействие с OpenAI

---

## 1. Верификация пользователя

### Функция: verify_user_appkey(username: str, appkey: str)

#### Описание
Эта асинхронная функция проверяет, существует ли пользователь с указанным именем и соответствует ли предоставленный приложенческий ключ (appkey).

#### Параметры:
- username (str): Имя пользователя, которого необходимо проверить.
- appkey (str): Приложенческий ключ, который должен соответствовать зарегистрированному пользователю.

#### Возвращаемое значение:
- Если верификация успешна, возвращает словарь с кодом состояния 200 и сообщением о успешной авторизации.
- Если верификация не удалась, выбрасывает исключение HTTPException с кодом 401 и соответствующим сообщением об ошибке.

#### Ошибки:
- 401 UNAUTHORIZED: 
    - Неверное имя пользователя.
    - Пользователь заблокирован (с указанием времени блокировки).
    - Неверный приложенческий ключ (с указанием количества неудачных попыток).

---

## 2. Взаимодействие с OpenAI

### Эндпоинт: /api/chat/

#### Метод: POST

#### Описание
Этот эндпоинт принимает запросы от пользователей для генерации ответов на основе входных данных через модель OpenAI.

#### Параметры запроса:
- user_input (объект JSON):
    - username: Имя пользователя.
    - system_content: Содержимое системного сообщения для AI.
    - user_content: Сообщение от пользователя для AI.
    - model: Модель OpenAI, которую следует использовать.

- appkey (строка, заголовок): Приложенческий ключ для аутентификации пользователя.

#### Возвращаемое значение:
- Если проверка пользователя прошла успешно, возвращает объект JSON с полем "response", содержащим ответ от модели AI.

#### Ошибки:
- Если происходит ошибка в процессе проверки (verify_user_appkey), возвращает ошибку 401 UNAUTHORIZED с соответствующим сообщением.
