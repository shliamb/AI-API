


## Json запросы к  API:

- В теле запроса Json есть поле username, проверяется на наличие в базе, не заблокирован ли и есть ли бабки. Далее проверяется его API Key соотвествующий именно этому пользователю, так я смогу блокировать и осуществлять простейшую временную блокировку к простукиванию API. 

- Если попытка обращения к API пользователя была не успешной (попытки без наличия средств, не верный ключ, заблокирован пользователь..), то через 5 попыток (не успешные попытки будут вноситься в базу, при успешном входе снова обнуляться), пользователь временно блокируется, для того, что бы сбрасывать его просто по имени.

## Получение доступа к работе с API:

Телеграм бот, нажимаем старт - регистрация выполнена, забираем доступы и какую то сумму тестовую на балансе, читаем инструкцию и можно уже обращаться через постман или писать приложение, прикручивать к своему приложению..

Возможно, бота закину в группу, попробую этот вариант, что бы понять плюсы и минусы, а может и нет.

## !!! Нюансы..

- API будет работать на серсере далеких стран, для обхода нынешних и возможных ограничений.
- Трафик не будет шифроваться, так как API работает без домена по http. При удачном стечении обстоятельств и расширении проекта, куплю домен .com и подлючу SSL по https шифрование. А пока что так..

- Удалять ключи если ими не пользовались какое то время. В админке для этого будет кнпока - clean. Пользователь снова сможет посетить бота и получить ключ.
